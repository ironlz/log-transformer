# 可配置化超大文件数据解析服务 · 项目文档索引

> 本目录由源文档《可配置化超大文件数据解析服务架构设计文档（v1.0）》拆分重组而来。
> 文档按**文档类型**分为六类目录：`design` / `iterators` / `bugs` / `references` / `others` / `test`。
> 设计类内部采用「总 — 分」结构：一份**总体设计**统领全局，多份**模块/功能详细设计**分述各子系统。
> 全部文档已完成自洽性校验，跨文档术语、数值与引用口径一致，详见 [`references/99-自洽性校验报告.md`](references/99-自洽性校验报告.md)。

## 系统一句话定位

**半结构化超大文件（最高 80GB）配置化解析与 KV 衍生服务**：按可配置规则将格式混布嵌套的本地半结构化文件解析为标准化键值对（KV），经算子链转换与衍生后输出；通过流式管道、有界内存、mmap 零拷贝、DAG 静态分析与投影下推，实现在极端文件规模下**线性时间、有界内存、不爆内存**。
