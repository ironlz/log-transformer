# 09 · 错误处理与可观测性

> 所属项目：可配置化超大文件数据解析服务
> 文档类型：模块详细设计（错误处理与可观测性）
> 上游依据：[01-总体设计.md](01-总体设计.md)、[06-依赖分析与并行调度.md](06-依赖分析与并行调度.md)、[08-执行流程详解.md](08-执行流程详解.md)

本文档定义错误分类与处理策略、断点续跑、进度监控、性能指标采集。

---

## 1. 错误分类与处理策略

| 错误类型 | 处理策略 | 是否中断 |
| --- | --- | --- |
| 配置错误 | 启动阶段 fail-fast，明确报错位置和原因，拒绝启动 | 是（启动前） |
| 分块错误 | 分隔符不匹配时记录告警，跳过该块或按容错策略（截断/补全）处理 | 否 |
| 解析错误 | 字段格式异常时记录原始数据到错误日志，保留原始字符串，继续处理 | 否 |
| 算子错误 | 计算异常时按配置重试（指数退避，最多 N 次），失败则跳过该批次或终止链路 | 可配置 |
| IO 错误 | 磁盘读失败时重试有限次数（默认 3 次），失败则终止并记录已处理进度 | 是（重试后） |
| 内存错误 | spill 失败或堆内存超限时优雅降级：降低并行度、强制 spill、暂停非关键链路 | 否（降级） |

---

## 2. 断点续跑

- 定期保存检查点（默认每处理 1000 个 Block 或每 30 秒）：已处理 Block 列表、算子状态快照、输出偏移量。
- 检查点以 append-only 格式写入本地磁盘，崩溃后可恢复到最近检查点。
- 重启时从检查点恢复，跳过已完成的 Block，从中断处继续。
- **幂等保证**：同一 Block 重复处理不产生重复输出（输出端基于 blockId 去重）。
- 检查点文件在任务正常完成后自动清理。

---

## 3. 进度监控

| 指标类别 | 具体指标 | 输出方式 |
| --- | --- | --- |
| 处理进度 | 已处理字节数/总字节数、已处理 Block 数/总 Block 数、完成百分比 | Prometheus metrics + 状态文件 |
| 处理速率 | KV 产出速率（条/秒）、字节处理速率（MB/s）、预估剩余时间 | Prometheus metrics |
| 内存使用 | 当前堆内存、mmap 大小、spill 文件总大小、队列深度 | Prometheus metrics |
| 执行状态 | 活跃链路数、当前波次、各算子调用次数、各算子平均耗时 | Prometheus metrics + 日志 |
| 错误统计 | 分块错误数、解析错误数、算子错误数、IO 错误数、错误详情 | 错误日志 + Prometheus metrics |

---

## 4. 性能指标采集

- **各阶段耗时**：配置加载、索引扫描、数据加载与处理（含依赖块优先加载与维表构建）、结果输出，分别计时。
- **各算子耗时与调用次数**：定位性能瓶颈算子。
- **IO 统计**：读次数、读字节数、随机读次数、顺序读字节数、spill 读写量。
- **GC 统计**（语言相关）：GC 次数、GC 总停顿时间、堆使用趋势。
- 性能报告在任务完成后输出，支持 JSON 格式便于自动化分析。
